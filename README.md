- **일정 탭**: 9.16~9.26 일자별 카드 (날씨/옷차림, 숙소, 교통편, "오늘 뭐 먹지?" 버튼)

## 민감정보 취급 원칙

이 저장소는 **Public**이라 링크를 아는 사람은 누구나 볼 수 있습니다. 다음은 절대 올리지 않습니다.

- 여권번호 · 여권 사진 · 생년월일
- eTA / ESTA 신청번호 (신청번호+여권번호+생년월일이면 제3자가 승인 정보를 조회·변경할 수 있음)
- 카드번호 등 결제수단 정보

항공·숙소 **예약번호는 앞 3~4자리만** 표시합니다. 성(姓)+예약번호 조합으로 예약 조회·변경·취소가 가능하기 때문입니다. 전체 번호는 각 예약 확정 메일에서 확인하세요.

탑승객 실명, 좌석번호, 숙소 주소는 이동에 필요해 그대로 두었습니다. 링크를 외부에 공유하지 마세요.
